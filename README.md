# homebrew-tap

Homebrew tap for [baedonguri/aiwitch](https://github.com/baedonguri/aiwitch).

## Install

```sh
brew install baedonguri/tap/aiwitch
```

Or tap once and install by short name:

```sh
brew tap baedonguri/tap
brew install aiwitch
```

## Formulae

| Formula | Description |
|---|---|
| [`aiwitch`](Formula/aiwitch.rb) | Multi-account / multi-profile switcher for AI CLIs (Codex, Claude Code, ...) |
